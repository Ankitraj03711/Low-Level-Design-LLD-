# Low-Level Design (LLD) in C++

Welcome to my Low-Level Design (LLD) learning repository.

This repository documents my journey of learning LLD using C++. It contains implementations of Object-Oriented Programming (OOP), SOLID principles, Design Patterns, UML diagrams, and real-world LLD problems.

## 📚 Topics Covered

- Object-Oriented Programming (OOP)
  - Classes & Objects
  - Encapsulation
  - Abstraction
  - Inheritance
  - Polymorphism

- SOLID Principles
  - Single Responsibility Principle
  - Open/Closed Principle
  - Liskov Substitution Principle
  - Interface Segregation Principle
  - Dependency Inversion Principle

- Design Patterns
  - Singleton
  - Factory
  - Strategy
  - Observer
  - Builder
  - Adapter
  - Decorator
  - Command
  - Prototype
  - And more...

- UML Diagrams
  - Class Diagram
  - Sequence Diagram

- Real-World LLD Problems
  - Parking Lot
  - Tic-Tac-Toe
  - Library Management System
  - Elevator System
  - Splitwise
  - ATM
  - BookMyShow
  - Snake & Ladder

## 🛠️ Language

- C++
